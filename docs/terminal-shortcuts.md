# Terminal Keyboard Shortcuts

The Multi-AI Terminal provides several keyboard shortcuts to enhance productivity and accessibility in the web UI.

## General Navigation
- **Escape (`Esc`)**: Closes active modal dialogs, side drawers, popups, and the customize drawer.
- **Tab (`Tab`) / Shift + Tab (`Shift+Tab`)**: Cycles focus through interactive elements. In side drawers and modals, focus is trapped within the open component to ensure accessibility.

## Workspace Panels
- **Arrow Left (`←`) / Arrow Right (`→`)**:
  - **Panel Resizing**: When focused on panel dividers (separators), these keys resize the Launchpad and activity inspector widths.
  - **Evidence View**: When focused on the evidence view tabs in the Run Workspace, these keys switch between the **Conversation** and **Timeline** views.

## Component Specific
- **Provider Setup**: Press `Escape` to close the provider setup popup menu.
- **Customize Drawer**: Press `Escape` to close the workflow customize drawer and return focus to its trigger button.
